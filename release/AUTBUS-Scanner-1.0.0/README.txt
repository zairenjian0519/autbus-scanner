AUTBUS Scanner 1.0.0

Install:
1. Unzip this package on the target Windows machine.
2. Double-click install.cmd.
3. Use the desktop shortcut "AUTBUS Scanner" to start the app.

Runtime:
- Web UI: http://localhost:3001
- WebSocket service: ws://localhost:8082
- UDP discovery port: 6060

Notes:
- No separate Node.js installation is required.
- Allow Windows Firewall access when prompted, otherwise UDP discovery and WebSocket access may be blocked.
- Keep the command window open while using the app. Closing it stops the local service.
