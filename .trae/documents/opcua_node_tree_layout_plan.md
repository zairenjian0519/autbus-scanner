# OPC UA 节点树布局调整计划

## 问题分析

用户反映 OPC UA 节点树显示界面只有两行不能显示，需要将其往上移动一些以解决显示不全的问题。

### 当前布局结构

1. **DeviceDetails 组件**：包含多个卡片，按顺序排列：
   - 设备基本信息卡片
   - 子设备卡片（如果有）
   - 属性点表卡片（如果有）
   - OPC UA 节点树卡片（仅控制器设备）

2. **OPCUANodeTree 组件**：当前设置为固定高度 600px，包含左右两个面板和底部任务栏

### 问题原因

1. 页面垂直空间有限，OPC UA 节点树卡片位于页面下方，可能被浏览器视口截断
2. 其他卡片占用了较多垂直空间
3. OPC UA 节点树本身高度固定，无法根据可用空间自动调整

## 解决方案

### 方案 1：调整 OPC UA 节点树卡片位置

将 OPC UA 节点树卡片移动到设备基本信息卡片之后，子设备和属性点表卡片之前，这样可以获得更多的垂直空间。

### 方案 2：调整 OPC UA 节点树高度

减小 OPC UA 节点树的固定高度，使其能够在有限的空间内完整显示。

### 方案 3：使用响应式布局

修改布局为响应式，根据屏幕高度自动调整各卡片的大小和位置。

## 实施计划

### 步骤 1：调整 OPC UA 节点树卡片位置

修改 `DeviceDetails.tsx` 文件，将 OPC UA 节点树卡片移动到设备基本信息卡片之后。

### 步骤 2：优化 OPC UA 节点树高度

调整 `OPCUANodeTree.tsx` 文件中的高度设置，使其更加合理。

### 步骤 3：测试布局效果

启动应用，测试调整后的布局是否能够完整显示 OPC UA 节点树的所有内容。

## 风险评估

1. **布局调整风险**：移动卡片位置可能会影响用户习惯的操作流程
2. **高度调整风险**：减小高度可能会影响节点树的显示效果
3. **响应式布局风险**：实现响应式布局可能需要更多的代码修改

## 预期效果

- OPC UA 节点树能够完整显示，没有内容被截断
- 布局美观，用户操作方便
- 适应不同屏幕尺寸的显示需求
